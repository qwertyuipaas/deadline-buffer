Section 1

Colour Palette

Every colour has exactly one semantic role. Using a colour for a different purpose is a deliberate signal, not an accident.

Ink #16192b
Primary text, headings, primary action buttons, and the nav bar background.
Paper #f6f6f3
Main page background. Warm off-white keeps the screen from feeling clinical.
Buffer #0e8f82
Safe buffer zone, on-track states, focus rings, and all positive / calm signals.
Deadline #e1512c
Work window in buffer bar, overdue badges, high-priority labels, and urgency alerts.
Highlight #eab13a
Medium priority, group project badges, and approaching deadline warnings.
Muted #6b7280
Secondary labels, metadata, placeholder text, and inactive states.
Surface #ffffff
Cards, modals, drawers, and input fields — raised surfaces above the page background.
Border #e5e7eb
Card outlines, dividers, input borders (default, unfocused state).

Section 3

Spacing System

One base unit: 4px. All spacing values are multiples of 4. This creates visual rhythm and makes padding, gap, and margin decisions predictable.

space-1 4px
Icon nudges, tight inline gaps
space-2 8px

space-3 12px

space-4 16px
Card inner padding (mobile), input padding
space-6 24px
Card inner padding (desktop), section gap
space-8 32px

space-10 40px
Page-level vertical rhythm, hero top padding
space-16 64px
Landing section breaks, large structural gaps

Summary

Design Decisions

Decision Choice Why
Background colour #f6f6f3 Paper Pure white feels clinical; warm off-white is calmer and matches the app's "less stress" goal.
Accent colour #0e8f82 Teal Teal reads as calm, safe, and in-control — exactly the feeling a student should get when their buffer is healthy.
Alert colour #e1512c Red-orange Warm red-orange is urgent without being as aggressive as pure red, matching "start now" not "you failed".
Display font Space Grotesk Geometric, slightly playful, and great for numeric data. Stands out from the neutral Inter body text.
Body font Inter The most legible UI typeface at small sizes on screens. Zero distraction.
Spacing base unit 4px 4px aligns with how Tailwind CSS generates its spacing scale, keeping design and code in sync.
