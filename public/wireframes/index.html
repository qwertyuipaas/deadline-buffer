3. React Component Breakdown

Repeated pieces broken out as components → these become the src/components/ folder.

Component File Used On What it renders / owns
Navbar shared Navbar.jsx All pages Logo, nav links, user avatar dropdown, sign-out button. Reads auth session from Supabase context.
BufferBar shared BufferBar.jsx Project View, Task Drawer, Landing demo Visual timeline bar split into teal "safe buffer" zone and orange "work window" zone. Props: deadline, hours, priority.
TaskCard shared TaskCard.jsx Project View One task row: name, hours, assignee, priority badge, BufferBar, start-by date, status dropdown, edit button. Props: task, onStatusChange, onEdit.
StatCard shared StatCard.jsx Dashboard Small metric tile showing a label + number (Active tasks, Done, Projects, Buffer Health). Props: label, value, icon.
ProjectCard shared ProjectCard.jsx Dashboard Project summary card: name, type badge, progress bar, next deadline. Clickable → navigates to /projects/:id.
AddTaskDrawer project AddTaskDrawer.jsx Project View Slide-in panel with task form. Calculates and previews start-by date live as user types. Props: open, onClose, onSave, members.
TeamPanel project TeamPanel.jsx Project View (group only) Lists teammates with capacity bars and remove buttons. Add-teammate input row. Props: members, onAdd, onRemove.
ProductTour shared ProductTour.jsx Dashboard, Project View Step-by-step tooltip overlay teaching new users how to use the app. Triggered by the "Guide" button in the navbar.
InteractiveDemo landing inline in Landing.jsx Landing The live demo panel where a guest can adjust hours and priority and see the buffer bar recalculate in real time.
